# La Plazuela · Un plan para 2025

Vídeo ejecutivo (Remotion, 1920×1080, 30 fps) para el caso de Herramientas Digitales (UFV).

- Narración: `public/narracion.mp3` (153,8 s). Duración del vídeo: 156,3 s.
- `scripts/align.py`: alinea el guion con las pausas del audio → `src/data/timeline.json` (subtítulos y cortes de escena).
- `npm run stills`: genera los fotogramas de revisión en `stills/`.
- `npm run render`: render final en `out/video.mp4`.
